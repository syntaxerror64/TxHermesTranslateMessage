# TxHermesTranslateMessage — Translate Guard

**Автоперевод исходящих сообщений в Hermes Agent — пишите на своём языке, отправляйте на языке собеседника.**

Translate Guard — плагин Hermes Agent (агентная и desktop-половины в одном пакете), который
переписывает черновик в поле ввода через каскад публичных движков перевода прямо перед
отправкой. В чате сохраняется переведённое сообщение, оригинал остаётся доступен, а в
композере редактирования можно переключаться между ними.

## Что делает

| Поверхность | Поведение |
|---|---|
| Композер (кнопка **▾** справа от кнопки отправки) | Меню: переключатель **автоперевода** и целевой язык (English / 中文) |
| Отправка | Черновик переводится каскадом движков и отправляется; в чате видно перевод |
| Композер редактирования | Рядом с его кнопкой отправки появляется значок переводчика; клик переключает текст редактора между оригиналом и переводом |
| Настройки ▸ Плагины ▸ Translate Guard | Дублирует переключатель и язык, показывает живое состояние движков (circuit breaker'ы) и очищает кэш переводов |

Состояние по умолчанию: **автоперевод включён**, целевой язык — **английский**. Китайский
включается одним кликом.

## Установка

### Из приложения (рекомендуется)

1. Скопируйте ссылку на репозиторий:

   ```
   https://github.com/syntaxerror64/TxHermesTranslateMessage
   ```

2. В Hermes Agent откройте **Возможности ▸ Плагины** (или **Настройки ▸ Плагины**).
3. Вставьте ссылку в поле **импорта** плагина и подтвердите.
4. Когда установка завершится, включите **Translate Guard**.

Приложение само клонирует репозиторий, проверяет его сканером и ставит обе половины **одной**
записью в списке плагинов.

### Из CLI

```bash
hermes plugins install https://github.com/syntaxerror64/TxHermesTranslateMessage
hermes plugins enable translate-guard
```

Затем перезапустите приложение или выполните **⌘K → Reload desktop plugins**, чтобы
материализовалась desktop-половина.

## Как пользоваться

- Кнопка **▾** стоит справа от кнопки отправки в композере.
- Клик открывает меню: включить/выключить **автоперевод**, сменить целевой язык.
- При включённом автопереводе набранный текст переводится до отправки — в чате остаётся
  перевод.
- После отправки откройте сообщение в **композере редактирования**: значок переводчика рядом
  с кнопкой отправки переключает между переводом и оригиналом.

## Движки перевода

Запрос идёт каскадом: побеждает первый ответивший движок, упавший пропускается до истечения
его окна back-off:

1. **Google** (translate.google.com)
2. **Mozhi** (шесть зеркал)
3. **SimplyTranslate**
4. **Lingva**
5. **MyMemory** (у бесплатного тарифа дневная квота символов; ошибка квоты обрабатывается —
   движок ставится на паузу, а не роняет запрос)

API-ключ не нужен. Движок, который ответил, показывается на странице настроек, а удачный
перевод кэшируется на 7 дней, поэтому повторное сообщение ничего не стоит.
**Настройки ▸ Плагины ▸ Translate Guard ▸ Очистить кэш** сбрасывает кэш, когда нужно, чтобы
движки спросили заново.

## Приватность

Текст отправляется публичному движку перевода, который ответил на запрос (Google, Mozhi,
SimplyTranslate, Lingva или MyMemory). Больше ничего с машины не уходит: ни аккаунтов, ни
телеметрии, ни хранения ваших переписок на стороне плагина. Если для какого-то сообщения это
неприемлемо — выключите автоперевод перед отправкой.

## Как устроен плагин

```
plugin.yaml              ← манифест плагина Hermes
__init__.py              ← агентная точка входа (регистрирует dashboard API)
dashboard/manifest.json  ← объявление API (скрытая вкладка, только REST)
dashboard/plugin_api.py  ← FastAPI-роутер: POST /translate (+ /health, /engines)
desktop/plugin.js        ← desktop-половина: меню композера, middleware отправки,
                            переключатель в редактировании, страница настроек
```

Desktop-половину не копируют руками: приложение само материализует
`plugins/translate-guard/desktop/` в свой каталог `desktop-plugins/` с маркером
`.hermes-package.json` — именно это держит плагин **одной** записью в списке.

### HTTP API

`POST /api/plugins/translate-guard/translate`

```json
{ "text": "привет, как дела?", "to": "en" }
```

```json
{ "text": "hi, how are you?", "engine": "google", "ms": 412, "cached": false }
```

`GET /api/plugins/translate-guard/health` — состояние circuit breaker'ов движков.

## Требования

- Hermes Agent с поддержкой плагинов (desktop-приложение или CLI).
- Python 3.10+ (используется рантайм Hermes; `httpx` и `fastapi` в нём уже есть).
- Сетевой доступ к перечисленным движкам перевода.

## Если что-то не работает

**Меню не открывается.** Обновите плагин и выполните **⌘K → Reload desktop plugins** (или
перезапустите приложение). В старых сборках на триггере стоял guard, который не давал меню
открыться.

**Сообщения уходят без перевода.** Плагин намеренно работает по принципу fail-open: если
бэкенд не ответил в отведённое время, сообщение отправляется как написано и появляется
предупреждение. Проверьте, что бэкенд Hermes запущен (в desktop-логе при его перезапуске
видно `ECONNREFUSED 127.0.0.1:9119`), и повторите.

**Перевод медленный или пустой.** Один из движков может быть ограничен по частоте или лежать;
каскад его пропускает и идёт дальше. Страница настроек показывает, какие движки открыты.
Быстрее всех исчерпывается бесплатная дневная квота MyMemory.

## Удаление

```bash
hermes plugins remove translate-guard
```

Если приложение оставило каталог `desktop-plugins/translate-guard/`, удалите его и
перезапустите.
